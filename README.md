# 波の3つの見方（仮称）

生徒が撮影した波の動画と、手描き作図の連番写真から、y-x図・y-t図・ぱらぱら漫画を連動して見せる高校物理のWebアプリ。

- 段階：試作版（実装 0.1）。仕様は 0.2。実機での確認はこれから（[docs/README.md](docs/README.md) の「引き継ぎ」）。
- 仕様書：[docs/README.md](docs/README.md)
- 共通の前提：[docs/common/](docs/common/)（全アプリ共通の仕様書群からの写し）

## 使い方

`index.html` をブラウザで開くだけで動く（インストール不要、動画や写真は端末の外へ送らない）。
カメラ映像を扱うため、公開は GitHub Pages など HTTPS で行う。

1. 「開く」で動画を選び、解析する区間を決めて「この区間を取り込む」。サンプルでも試せる。
2. 「y-t図をつくる」で、1か所を選ぶ → 点を打って予想する → 記録する → グラフから動画へ、の順に進む。
3. 「調べる」で、線の幅、y-t図の横軸（y-x図と同じ縮尺）、長さの目盛り、カメラの傾き、コマ数／秒、撮影倍率を変える。
4. 「用紙」でぱらぱら漫画の用紙を印刷し、生徒が赤で合成波を描いて撮影 → 「開く」で写真をまとめて選ぶ。
5. 「ぱらぱら漫画」で、赤い線だけの表示、全コマの重ね、答え合わせの線、コマの差し替え、教師用の「残りのコマを補う」を使う。

## 実装の状況（仕様 0.2 との対応）

| 範囲 | 状況 |
|---|---|
| 動画の取り込み（WAVE-F-01, F-06〜F-08, N-10, N-11） | 実装。`requestVideoFrameCallback` で全コマを縮小保存、取りこぼし時は速度を落として取り直し。使えない端末では1コマずつシーク |
| サンプル（F-03, §1.1） | 1〜4 をアプリ内で生成。5（実写）は `samples/real-wave.mp4` を置くと開ける（未同梱） |
| y-x図・位置線・y-t図（F-10〜F-14, F-20〜F-27） | 実装。2本の線は色を分けて同じ y-t図に重ねる |
| y-t図の見せ方（02-yt-animation） | 実装。画面の順は 1か所を選ぶ（段階1）→ 点を打って予想（段階4）→ 記録する（段階2・3を1本に）→ グラフから動画へ（段階5） |
| ぱらぱら漫画（F-30〜F-39） | 実装。ArUco の検出、射影変換、白基準の色補正、赤の抽出、手動での四隅指定、上下反転の補完 |
| 用紙の生成（F-60〜F-63） | 実装。A4 横、教師用の表紙つき。ブラウザの印刷で PDF にもできる |
| 保存（F-50, F-51） | y-t図・重ねた画像は PNG、ぱらぱら漫画は動画（mp4 または webm） |
| アプリ内での撮影（F-05） | 未実装（WAVE-Q-02 が未決）。スマホではファイル選択からカメラを起動できる |
| x-t図（F-40） | 初版の範囲外 |

## 開発

```
python3 build.py      # src/ をまとめて index.html を作る（Python 3 だけで動く）
```

```
.
├── index.html         配布用（build.py が生成。直接は編集しない）
├── build.py
├── src/
│   ├── app.html       画面の骨組み
│   ├── style.css
│   ├── LICENSE-js-aruco2.txt
│   └── js/            名前順に連結される
│       ├── 00-core.js      状態・共通の道具
│       ├── 05-aruco.js     js-aruco2（マーカー検出、MIT）
│       ├── 10-capture.js   動画の取り込み
│       ├── 15-samples.js   サンプルの生成
│       ├── 20-view.js      y-x図・位置線・再生
```
