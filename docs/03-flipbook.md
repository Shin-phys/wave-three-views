# ぱらぱら漫画

向かい合う波の合成波を作図して写真に撮り、順に撮影したものを読み込んで、ぱらぱら漫画として再生する機能。
この発想自体は【決定】、以下の具体的な仕様は【提案】である。

## 1. ねらい

- 定常波のシミュレーションを見せるのではなく、「自分の作図が動き、節だけが動かない」と気づかせる。
- 作図の動機づけにする。

## 2. 流れ

1. 用紙を配る（時刻ごとに入射波が印刷されている）。
2. 生徒が合成波を作図する。
3. スマホで撮影する。
4. アプリが位置合わせをして並べる。
5. 再生する。

## 3. 用紙の仕様

| 項目 | 内容 | 状態 |
|---|---|---|
| 四隅のマーカー | 位置合わせ用に四隅へ印刷する。 | 【提案】WAVE-Q-04 |
| コマ番号 | QR で印刷する。撮影順に関係なく自動で並べるため。 | 【提案】WAVE-Q-04 |
| 入射波 | 右向きの波と左向きの波を、その時刻の位置で印刷しておく。 | 【提案】 |
| 方眼 | 高さの足し算ができる方眼を入れる。 | 【提案】 |
| 合成波の色 | 赤で描かせる。色で抜き出すため。 | 【提案】WAVE-Q-10 |

## 4. コマ数

- T/4 刻みだと、合成波が「最大・平ら・逆向き最大・平ら」の4コマになり、動きがカクつく。
- T/8 刻み以上が要る（8コマ以上）。
- 波長と刻みの選び方で、作図する値が方眼に乗るかどうかが変わる。WAVE-Q-03 で決める。

| 刻み | 波長の例 | 方眼の交点での値（振幅を1として） |
|---|---|---|
| T/8 | 8マス | 0、0.71、1 |
| T/12 | 12マス | 0、0.5、0.87、1 |

## 5. 分担

- 1人で8枚を作図するのは、1回の授業に収まらない。
- 班や個人で1コマずつ分担し、クラス全員で1本のアニメを作る形が現実的である。
- 1コマでも作図を誤ると、そこだけ波が跳ねる。相互点検が自然に起きる。
- 少人数のクラスでの運用は WAVE-Q-11。

## 6. 位置合わせ

- 手持ち撮影はコマごとにずれる。そのままでは画面が揺れて節が見えない。
- 四隅のマーカーを検出し、台形補正をして切り出す（WAVE-F-30）。
- 検出に失敗したときは、手動で四隅を指定する（WAVE-F-31）。

## 7. 表示

| 機能 | 内容 | 要件 |
|---|---|---|
| 連続再生 | ループ、速度可変、コマ送り | WAVE-F-33 |
| 合成波の抽出 | 赤だけを抜き出す。入射波の表示を切り替える。 | WAVE-F-34 |
| 残像表示 | 全コマを薄く重ねる。腹と節の包絡線が一度に浮かぶ。 | WAVE-F-35 |
| コマ一覧 | 差し替え、削除 | WAVE-F-36 |
| y-t図との連動 | 位置線を節に置けば平らなまま、腹に置けば振幅2Aで振動する。 | WAVE-F-37 |
| 理論波形の重ね描き | 答え合わせ用。初期状態は非表示。 | WAVE-F-38 |

## 8. 汎用化

仕組みは「マーカー付き用紙の連番撮影→位置合わせ→再生」である。
定常波専用にせず、用紙を替えれば次にも使える形にする。

- 固定端反射、自由端反射
- パルスの重ね合わせ
