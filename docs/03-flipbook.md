# ぱらぱら漫画

向かい合う波の合成波を作図して写真に撮り、順に撮影したものを読み込んで、ぱらぱら漫画として再生する機能。
この発想自体は【決定】、以下の具体的な仕様は【提案】である。

## 1. ねらい

- 定常波のシミュレーションを見せるのではなく、「自分の作図が動き、節だけが動かない」と気づかせる。
- 作図の動機づけにする。

## 2. 流れ

1. アプリで用紙を印刷して配る（時刻ごとに入射波が印刷されている。WAVE-F-60）。
2. 生徒が合成波を作図する。
3. スマホで撮影する。
4. アプリが位置合わせをして並べる。
5. 再生する。

## 3. 用紙の仕様

| 項目 | 内容 | 状態 |
|---|---|---|
| 四隅のマーカー | ArUco マーカーを四隅へ印刷する。位置合わせとコマ番号の読み取りを兼ねる。 | 【決定】WAVE-Q-04 |
| コマ番号 | 四隅のマーカーの ID を用紙ごとに変えて表す（n 枚目の用紙は ID 4n〜4n+3）。QR は使わない。生徒向けに「t = 2T/8」などの表記も印刷する。 | 【決定】WAVE-Q-04 |
| 入射波 | 右向きの波と左向きの波を、その時刻の位置で印刷しておく。黒または濃い灰色で、右向きは実線、左向きは破線とする。 | 【決定】 |
| 方眼 | 高さの足し算ができる方眼を入れる（§4.1）。うすい水色で印刷し、読み取り時に色で消せるようにする。 | 【決定】 |
| 合成波の色 | 赤で描かせる。色で抜き出すため。太めの赤の水性サインペンを推奨する。 | 【決定】、抽出の安定性は【要検証】WAVE-Q-10 |
| 色の基準 | 用紙の余白（白）の色を基準にして、照明による色の偏りを補正してから赤を抜き出す。 | 【提案】 |

### 3.1 用紙の生成

- 【決定】用紙はアプリが生成する（WAVE-F-60〜F-63）。マーカー・コマ番号・入射波を正確に印刷する必要があり、手作りでは位置合わせや理論波形との比較が成り立たないため。
- 用紙の設定値をアプリが知っているので、理論波形の重ね描き（WAVE-F-38）が少ない手間で作れる。
- 【提案】印刷用ページには、教師用の表紙（コマ数・分担表・§4.3 の教師用メモ）を1枚付ける。

## 4. コマ数と方眼

### 4.1 決定事項（WAVE-Q-03）

- 【決定】T/8 刻みの8コマ（t = 0、T/8、…、7T/8）とする。T/4 刻みでは「最大・平ら・逆向き最大・平ら」の4コマになり、動きがカクつくため。
- 【決定】方眼の横の1目盛りを λ/8 とする（波長 = 横8目盛り）。入射波は1コマでちょうど横1目盛りずつ進む。
- 【決定】振幅 A を縦7目盛りとする。0.71A ≈ 4.95 なので、作図する値が整数に乗る（誤差約1%）。

| 量 | 値（縦の目盛り数） |
|---|---|
| 入射波の値 | 0、±5、±7 |
| 足した値 | 0、±5、±7、±10、±12、±14 |
| 合成波の最大 | ±14（= 2A） |

- 【提案】横の1目盛りを 15 mm、縦の1目盛りを 5 mm とする（長方形の方眼）。正方形の方眼で波長8マスにすると、振幅が波長とほぼ同じになり、山が縦に細長くなりすぎるため。描く範囲は横2波長（16目盛り＝24 cm）、縦 ±14目盛り（±7 cm）で、A4 横に収まる見込み。試し刷りで決める。
- 【提案】縦線は横の目盛り（λ/8 ごと）にだけ引き、生徒はその縦線の上で高さを足す。
- 【決定】用紙に収まらない場合の代案は、T/12 刻み・波長 = 横12目盛り・振幅 = 縦8目盛り（値は 0、±4、±7、±8）とする。

### 4.2 入射波の位相

- 【提案】右向きの波を A sin(kx − ωt)、左向きの波を A sin(kx + ωt) とする。t = 0 で2つが重なり、合成波は 2A sin kx になる。
- このとき節は横の目盛り 0、4、8、…、腹は 2、6、10、… の位置にくる。

### 4.3 教師用メモ（画面には出さない）

- t = 2T/8（= T/4）のコマでは、2つの入射波がすべての点で打ち消し合い、合成波は全面で0になる。生徒が「描き間違えた」と思いやすいので、机間指導で声をかける。
- 合成波の値が出るのは、横の目盛り上だけで十分である。その間はなめらかにつなぐ。

## 5. 分担

- 1人で8枚を作図するのは、1回の授業に収まらない。
- 班や個人で1コマずつ分担し、クラス全員で1本のアニメを作る形が現実的である。
- 1コマでも作図を誤ると、そこだけ波が跳ねる。相互点検が自然に起きる。

### 5.1 少人数のクラス（WAVE-Q-11）

- 【決定】教師用の設定で、半周期ぶん（t = 0、T/8、2T/8、3T/8 の4枚）を描けば、残りの4枚をアプリが作れるようにする（WAVE-F-39）。初期状態はオフ。
- 根拠：t + T/2 では、右向きの波も左向きの波も符号が反転する（sin(θ − π) = −sin θ）。そのため用紙全体（入射波も合成波も）が、t のコマを横軸について上下反転したものになる。
- 反転するのは位置合わせ後の作図範囲だけで、マーカーは含めない。
- 4枚なら、2〜4人で1コマずつ、または1人2枚で分担できる。
- この性質に生徒自身が気づく余地を残すため、画面には「上下反転」と表示しない（WAVE-N-05）。表示名は「残りのコマを補う」とする。【提案】

## 6. 位置合わせ

- 手持ち撮影はコマごとにずれる。そのままでは画面が揺れて節が見えない。
- 四隅のマーカーを検出し、台形補正をして切り出す（WAVE-F-30）。
- 検出に失敗したときは、手動で四隅を指定する（WAVE-F-31）。

### 6.1 マーカーの方式（WAVE-Q-04）

- 【決定】ArUco マーカーを使い、四隅の ID でコマ番号も表す。1回の検出で、位置合わせ・用紙の向き・コマ番号がそろう。
- 【決定】QR は使わない。iOS の Safari では `BarcodeDetector` が使えない見込みで、別の読み取りライブラリが要るため。
- マーカー1個からでも4つの角が取れるので、指などで一部のマーカーが隠れても補正できる。四隅のうち2個以上が見つかれば、位置合わせを行う。【提案】
- 辞書（マーカーの種類）は、検出ライブラリが対応するものから選ぶ。T/12（12枚・48個）まで ID が足りること。【要検証】

## 7. 表示

| 機能 | 内容 | 要件 |
|---|---|---|
| 連続再生 | ループ、速度可変、コマ送り | WAVE-F-33 |
| 合成波の抽出 | 赤だけを抜き出す。入射波の表示を切り替える。 | WAVE-F-34 |
| 残像表示 | 全コマを薄く重ねる。腹と節の包絡線が一度に浮かぶ。 | WAVE-F-35 |
| コマ一覧 | 差し替え、削除 | WAVE-F-36 |
| y-t図との連動 | 位置線を節に置けば平らなまま、腹に置けば振幅2Aで振動する。 | WAVE-F-37 |
| 理論波形の重ね描き | 答え合わせ用。初期状態は非表示。 | WAVE-F-38 |

## 8. 汎用化

- WAVE-F-39（上下反転で補う）は定常波の用紙だけに使える。パルスなど他の用紙では使えない。


仕組みは「マーカー付き用紙の連番撮影→位置合わせ→再生」である。
定常波専用にせず、用紙を替えれば次にも使える形にする。

- 固定端反射、自由端反射
- パルスの重ね合わせ
