# 波の3つの見方（仮称）

## 1. 概要

生徒が撮影した波の動画と、手描きした作図の連番写真を入力にして、次の3つを連動して見せるアプリ。

| 見方 | 作り方 | 対象 |
|---|---|---|
| y-x図 | 動画の1コマ（時刻を止める） | 実写動画・手描き連番 |
| y-t図 | 1か所の縦の画素列を時間順に並べる（場所を固定する） | 実写動画・手描き連番 |
| ぱらぱら漫画 | 手描きの作図を位置合わせして連続再生する | 手描き連番（定常波など） |

動画は y(x, t) そのものなので、時刻を止めれば y-x図、場所を固定すれば y-t図になる。生徒がつまずきやすい2つの図の対応を、1画面で扱うことがねらいである。

## 2. ねらい

- y-t図は「媒質の1点の履歴」であり、波の形の写真ではないことを体感させる。
- 向かい合う波の合成波を自分で作図し、それが動くことで定常波（節は動かず、腹が大きく振動する）を見出させる。
- 手描きの連番にも同じ道具が使えることを通して、作図と実物の波を同じ見方でつなぐ。

## 3. 決定事項

- 【決定】入力は、生徒が撮影した実物の波の動画と、手描き作図の連番写真とする。シミュレーションを主にはしない。
- 【決定】保険として、サンプル動画（シミュレーション）を同梱する。
- 【決定】y-x図、y-t図、ぱらぱら漫画（定常波）を1つのアプリに統合する。

## 4. 当面の範囲外

- x-t図（横の線を時間順に積む図）は発展扱いとする。
- 弦や音叉のような速い振動は対象外。30 fps の動画で扱えるのは数Hzまでである。
