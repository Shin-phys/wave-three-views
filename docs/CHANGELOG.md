# 改訂履歴：波の3つの見方

## 0.2（2026-10-12）

- README の決定事項と引き継ぎを更新。
- y-t図の時間軸の伸縮と、y-x図と同じ縮尺にそろえる機能を追加（WAVE-F-27）。
- カメラの傾きを補正する機能を追加（WAVE-F-14）。
- 用紙の印刷色を決定（方眼はうすい水色、入射波は黒・灰で実線と破線、合成波は赤）。白を基準にした色補正を提案（WAVE-Q-10 は検証待ち）。
- フレームレートの推定と手入力、撮影倍率の入力を追加。iPhoneは互換性優先で撮る案内を追加（WAVE-F-07、F-08、N-04、WAVE-Q-09 は検証待ち）。
- x-t図は初版に入れないと決定（WAVE-Q-08、WAVE-F-40）。
- スマホは横持ちを推奨とし、縦持ちでは切り抜いた動画とy-t図を横に並べると決定（WAVE-Q-05、WAVE-N-12）。
- サンプルの内容を決定。シミュレーションはアプリ内で生成し、実写のお手本だけmp4で置く（WAVE-Q-06、WAVE-F-03、F-04）。
- ぱらぱら漫画の用紙をアプリ内で生成する機能を追加（WAVE-F-60〜F-63）。
- マーカーをArUcoに決定し、四隅のIDでコマ番号を表してQRを廃止（WAVE-Q-04、WAVE-F-30、F-32）。
- 半周期の4枚から残りを上下反転で補う教師用の設定を追加（WAVE-Q-11、WAVE-F-39）。
- ぱらぱら漫画をT/8の8コマ、横1目盛り＝λ/8、振幅＝縦7目盛りに決定。長方形の方眼を提案（WAVE-Q-03）。
- y-t図の見せ方の5段階をすべて初版に入れると決定。段階2をペン先が進む方式に変更（WAVE-Q-07、WAVE-F-10、F-12、F-21、F-22、F-26）。
- 動画のコマを読み込み時に全部縮小保存する方式と、解析区間の指定を追加（WAVE-F-06、WAVE-N-10、N-11）。
- 技術構成を単一HTMLを生成する構成に決定（WAVE-Q-01、WAVE-N-08）。使うライブラリの候補を追加（WAVE-N-09）。
- 共通設計原則を適用すると決定。設定欄を畳める仕様を追加（WAVE-Q-13、WAVE-N-01、N-02、N-05〜N-07）。
