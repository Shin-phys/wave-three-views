# 授業での使い方

全体が【提案】。実践を経て書き換える。

## 1. 想定する場面

- 波の表し方（y-x図と y-t図）
- 波の重ね合わせ
- 定常波

## 2. 流れの案A：実写動画から y-t図へ

1. ウェーブマシンなどの波を撮影する（三脚固定、暗い背景、媒質の先端に色シール）。
2. 動画をコマで止め、y-x図として見る。
3. 1か所をタップし、その点だけに注目する。
4. コマ送りしながら点の位置を打ち、続きを予想する。
5. 自動で y-t図を作り、予想と比べる。
6. 別の場所にも線を置き、2つの y-t図を比べる。

## 3. 流れの案B：作図からぱらぱら漫画へ

1. 時刻ごとの用紙を分担して配る。
2. 各自が合成波を赤で作図する。
3. 撮影して読み込む。
4. 再生し、動かない点と大きく動く点を探す。
5. 残像表示で全体の形を確かめる。
6. 動かない点と大きく動く点に線を置き、y-t図を比べる。

## 4. 準備物

| 案 | 準備物 |
|---|---|
| A | ウェーブマシンまたは長いばね、三脚、色シール、暗い背景 |
| B | 時刻ごとの作図用紙（コマ数ぶん）、赤ペン |

## 5. 時間

- 1回の授業（40分程度）に収まるかは要検証。
- 案Bは、分担しないと作図だけで時間を使い切る。
- 少人数のクラスでは、4枚だけ描いて残りをアプリで補う（WAVE-F-39）。

## 6. 生徒に見出させたいこと（教師用）

画面には出さない。

- y-t図は1点の動きの記録であること。
- 場所が違うと、同じ形が時間をずらして現れること。
- 定常波では、動かない点と大きく振動する点が交互に並ぶこと。
- 定常波には、全体が平らになる瞬間があること。
- 進む波の y-x図と y-t図は、形が左右反転すること（非対称パルスの場合）。
