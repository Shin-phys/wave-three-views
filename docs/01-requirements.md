# 要件

状態タグと ID の規則は `common/spec-conventions.md` を参照。
特に断りのない項目は【提案】である。

## 1. 入力

| ID | 要件 | 状態 |
|---|---|---|
| WAVE-F-01 | 端末内の動画ファイルを読み込める。処理は端末内で完結する。 | 【決定】 |
| WAVE-F-02 | 連番写真（手描き作図を撮影したもの）を複数枚まとめて読み込める。 | 【決定】 |
| WAVE-F-03 | 同梱のサンプル動画（シミュレーション）を選んで開ける。 | 【決定】 |
| WAVE-F-04 | 実写のサンプル動画も同梱する（撮り方のお手本を兼ねる）。 | 【提案】 |
| WAVE-F-05 | アプリ内でカメラを起動して撮影できる。 | 【提案】WAVE-Q-02 |
| WAVE-F-06 | 読み込んだ動画の解析区間（開始と終了）を指定できる。 | 【決定】 |

## 7. 非機能要件

| ID | 要件 | 状態 |
|---|---|---|
| WAVE-N-01 | 処理はブラウザ内で完結し、動画や写真を外部へ送信しない。 | 【決定】 |
| WAVE-N-02 | スマホ、タブレット、PC で動作する。PC・タブレットは左に映像、右に設定の2カラムを基本とする。映像の横に y-t図を並べる画面と、y-t図を作るアニメーションの間は、設定欄を畳める。 | 【決定】 |
| WAVE-N-03 | 対象は 30 fps の動画で数Hzまでの波とする。 | 【提案】 |
| WAVE-N-04 | 撮影条件（三脚固定、暗い背景、媒質の先端に色シール）を案内する。 | 【提案】 |
| WAVE-N-05 | タブ名やガイド文で結論を先に言わない。道具の説明と操作の指示だけにする。 | 【決定】 |
| WAVE-N-06 | 動画は縮小して処理するなど、スマホでも重くならないようにする。 | 【決定】 |
| WAVE-N-07 | ボタンはタブレットやスマホで押しやすい大きさにする。 | 【決定】 |
| WAVE-N-08 | 技術構成：`src/` を編集し、ビルドスクリプト（`build.py`）で単一の `index.html` を生成する。外部ライブラリはインライン化する。GitHub Pages で公開する。 | 【決定】 |
| WAVE-N-09 | 使うライブラリは小さいものに限る。候補はマーカー検出に js-aruco2、GIF 書き出しに gif.js、動画書き出しはブラウザの MediaRecorder。OpenCV.js（約8 MB）は使わない。 | 【提案】 |
| WAVE-N-10 | 動画は解析区間を1回だけ再生し、`requestVideoFrameCallback` で全コマを縮小して端末内のメモリに保存する。コマの取りこぼしがあれば再生速度を落として（0.5倍など）取り直す。以後のコマ送り、y-t図の生成、アニメーションは保存したコマから行う。`currentTime` の指定によるコマ送りは、ずれや取りこぼしが起こるため使わない。 | 【決定】 |
| WAVE-N-11 | 保存するコマは 320×180 画素程度、最大300コマ（30 fps で10秒）を目安とする（約50 MB）。スマホで動くかを確かめて決める。 | 【要検証】 |
