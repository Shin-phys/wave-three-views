# y-t図の見せ方

y-t図の概念形成には、動画から y-t図を作る過程の見せ方が重要である、という考えに基づく文書。

- 【決定】5つの段階はすべて初版に入れる（WAVE-Q-07）。
- 【決定】実装は段階1→2→3→5→4 の順に進める。段階5は保存したコマ（WAVE-N-10）から時刻を引くだけで作れる。段階4は打点の操作画面が要るので最後にする。
- 【決定】段階1〜3は1本の続いたアニメーションとし、速度を変えられるようにする。
- 「3. 発展」は【提案】のままとする。
- 【決定】画面の手順は「1か所を選ぶ（段階1）→ 点を打って予想する（段階4）→ 記録する（段階2・3）→ 場所を変えて調べる」の4つとする（§2.1）。

## 1. 核になる考え

y-t図は「媒質の1点の履歴」であって、波の形の写真ではない。
このことを、説明ではなく画面の動きで体感させる。

## 2. 5つの段階

段階は「次へ」で1つずつ進む。

### 段階1：1点だけ残す

- 動き：タップした場所の縦の細い帯だけを明るく残し、他を暗くする。
- ねらい：波の形が見えなくなり、「上下に動く1個の点」だけが残る。注目する対象が波全体から1点へ移る。

### 段階2：高さを横に写す

- 動き：動画の右隣に同じ縦スケールのグラフを置く。点の高さからペン先まで水平のガイド線を引く。グラフの紙は止めたまま、ペン先が一定の速さで右へ進み、跡が残る。【決定】
- ねらい：横軸が場所ではなく時間であることが、ペン先の進みとして見える。
- 設計上の注意：ガイド線を水平に引くため、動画とグラフは横並びで、縦スケールをそろえる必要がある。スマホは横持ちを推奨とする。縦持ちでは、段階1で残す細い帯のまわりだけを切り抜いた動画を左に、グラフを右に置く（WAVE-N-12）。
- 設計上の注意（時間軸の向き）：ペンを固定して紙を流す見せ方（地震計型）は採らない。グラフが動画の右にあると、古い記録が右へ流れ、右ほど過去になる。ふつうの y-t図と左右が逆になり、非対称パルスで扱う「左右反転」の混同を招く。地震計の見せ方を使いたい場合は、グラフを動画の**左**に置き、紙を左へ流せば向きが正しくなる。

### 段階3：コマを切り出して並べる

- 動き：帯を1コマずつ切り取り、グラフ側に左から並べる。最初は5コマおきの太い帯でゆっくり、次第に細く速くして曲線にする。
- ねらい：グラフが動画の切れ端でできていることが分かる。8コマの手描きぱらぱら漫画ともそのままつながる。

### 段階4：先に生徒に打たせる

- 動き：自動再生の前に、コマ送りしながら点の位置をタップさせて打点させる。数点打ったところで続きを予想させ、それから自動で答え合わせをする。
- ねらい：生徒の操作を主役にする。予想と結果の差が学びになる。
- 【決定】打った点は色を変えて残す。そのコマを表示しているときは、どの手順でも y-x図に印が出て、y-t図の点も輪で強調される。一通り終えたあとにコマを送って見直すと、自分の打点と記録した y-t図を比べられる（WAVE-F-29）。

### 段階5：逆にたどる

- 動き：完成したグラフ上の点をタップすると、動画がその瞬間に飛ぶ。
- ねらい：「グラフのこの山は動画のどの場面か」を往復で確かめる。
- 【決定】手順4では補助の操作とし、説明は下に小さく書く（§2.1）。

### 2.1 手順4「場所を変えて調べる」

- 【決定】主の操作は、y-x図をタップして線を置き直すこと。指を離すと、その場所の y-t図が左から描かれる（WAVE-F-28）。いろいろな場所で試して y-t図を比べる。
- 【決定】2本目の線を置いて、同じ y-t図に重ねて比べられる（WAVE-F-13）。
- 【決定】自分で打った点と予想は、最初は隠し、チェックで表示できる。線を置き直したあとは古い場所の打点なので、混ざらないようにするため。
- 【決定】y-t図をタップして y-x図をその時刻へ移す操作（段階5）は、下に小さく案内する。

## 3. 発展

### 2か所の比較

- 色違いの位置線を2本置くと、同じ形が時間差で現れる。位相の遅れが見える。

### 非対称パルス

- 前が急で後ろがなだらかなパルスを使うと、y-x図と y-t図で形が左右反転することを示せる。
- 時間軸を y-x図と同じ縮尺にそろえる（WAVE-F-27）と、進行波の y-t図は y-x図のちょうど鏡像になり、比較がはっきりする。
- 生徒が混同しやすいところなので、サンプルに入れる（`01-requirements.md` §1.1 のサンプル2）。
