# y-t図の見せ方

y-t図の概念形成には、動画から y-t図を作る過程の見せ方が重要である、という考えに基づく文書。
全項目が【提案】で、どれを初版に入れるかは WAVE-Q-07 で決める。

## 1. 核になる考え

y-t図は「媒質の1点の履歴」であって、波の形の写真ではない。
このことを、説明ではなく画面の動きで体感させる。

## 2. 5つの段階

段階は「次へ」で1つずつ進む形を想定する。

### 段階1：1点だけ残す

- 動き：タップした場所の縦の細い帯だけを明るく残し、他を暗くする。
- ねらい：波の形が見えなくなり、「上下に動く1個の点」だけが残る。注目する対象が波全体から1点へ移る。

### 段階2：高さを横に写す

- 動き：動画の右隣に同じ縦スケールのグラフを置く。点の高さからペン先まで水平のガイド線を引く。記録紙が一定の速さで流れ、跡が残る（地震計の記録のような見せ方）。
- ねらい：横軸が場所ではなく時間であることが、紙の流れとして見える。
- 設計上の注意：ガイド線を水平に引くため、動画とグラフは横並びで、縦スケールをそろえる必要がある。スマホを縦に持ったときの配置は WAVE-Q-05。

### 段階3：コマを切り出して並べる

- 動き：帯を1コマずつ切り取り、グラフ側に左から並べる。最初は5コマおきの太い帯でゆっくり、次第に細く速くして曲線にする。
- ねらい：グラフが動画の切れ端でできていることが分かる。8コマの手描きぱらぱら漫画ともそのままつながる。

### 段階4：先に生徒に打たせる

- 動き：自動再生の前に、コマ送りしながら点の位置をタップさせて打点させる。数点打ったところで続きを予想させ、それから自動で答え合わせをする。
- ねらい：生徒の操作を主役にする。予想と結果の差が学びになる。

### 段階5：逆にたどる

- 動き：完成したグラフ上の点をタップすると、動画がその瞬間に飛ぶ。
- ねらい：「グラフのこの山は動画のどの場面か」を往復で確かめる。

## 3. 発展

### 2か所の比較

- 色違いの位置線を2本置くと、同じ形が時間差で現れる。位相の遅れが見える。

### 非対称パルス

- 前が急で後ろがなだらかなパルスを使うと、y-x図と y-t図で形が左右反転することを示せる。
- 生徒が混同しやすいところなので、サンプル動画に1本入れる価値がある（WAVE-Q-06）。

## 4. 段階と要件の対応
